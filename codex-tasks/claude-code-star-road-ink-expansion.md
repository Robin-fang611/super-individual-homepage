# Claude Code Task: 星路展开与水墨星光强化

## 任务目标

围绕现有个人主页的原始美术素材，增强 3D 场景里的“展开后的星路”。这次不要做建筑、观测台、浮岛、平台、塔、城堡或任何新地标；新增视觉只能服务于原图的填充、延展和融合。

最终效果要像原有星路从画面里自然展开：星光更密、更有纵深，水墨雾气把路径边缘柔化，整体避免塑料感和硬贴感。

## 必读上下文

执行前先读这些文件：

- `DESIGN.md`
- `docs/personal-homepage-design.md`
- `index.html`
- `styles.css`
- `src/app.mjs`
- `src/star-field.mjs`
- `src/star-layout.mjs`
- `tests/star-field-controls.test.mjs`
- `tests/star-layout.test.mjs`
- `tests/star-content.test.mjs`

项目是静态页面，没有 `package.json`，不要新增依赖。

## 核心设计方向

- 视觉母体是 `assets/images/star-road-hero-composed.png`。
- 3D 场景应该像原图星路的空间展开，而不是另起一个游戏场景。
- 左侧暗场要保留给 `Robin` 文案，不要让星路或粒子压住文字。
- 右上漩涡和右侧主星路是原构图核心，不能被新元素遮挡。
- 新增内容以“星光颗粒、柔性光河、水墨雾面、轻微路径脉动”为主。
- 节点只是被星路照亮的星标，不要做成大球、大 UI 标记或实体装置。

## 禁止项

- 禁止做建筑、观测台、浮岛、平台、塔、城堡、宗门山门。
- 禁止新增一条和原星路方向冲突的强光束或主路径。
- 禁止高饱和紫蓝渐变球、赛博网格、bokeh blob、大面积金色。
- 禁止纯白大光斑、硬边发光、厚重金属/玻璃/塑料材质。
- 禁止新增依赖。
- 禁止删除旧素材文件；如果需要清理废稿，先让 Robin 确认。

## 实现范围

优先改这些文件：

- `src/star-field.mjs`
- `styles.css`
- `index.html`，只在需要刷新缓存版本号时修改

尽量不要改内容数据、测试结构、布局文案和无关文件。

## 3D 实现要求

在 `src/star-field.mjs` 里完成：

- 保留现有 Three.js 架构和交互：拖拽、滚轮、键盘、节点点击、移动端底部面板都要继续可用。
- 沿现有 `pathCurve` 增加 2-4 层低透明 road ribbon，表现“展开后的星路”，不要做硬边实体带。
- 增加沿曲线分布的星尘粒子，粒子要有宽窄变化，集中在星路附近，不要均匀撒满全屏。
- 增加水墨感雾层：可以用 `CanvasTexture` 生成透明纹理，再用 `SpriteMaterial` 或半透明面片贴在星路边缘。
- 降低节点的塑料感：球体不要过大，不要强金属，halo 和 ring 要柔，当前节点只做星光密度增强。
- 远景装饰只能是星尘/雾/轻线条，不要变成独立地标。
- 动效要慢：呼吸、漂移、路径轻微流动即可，不要高速旋转或强闪烁。

## CSS 实现要求

在 `styles.css` 里完成：

- 保留左暗右亮构图，强化左侧文字可读性。
- 增加或调整全局叠层时，只能做暗角、柔雾、轻星点，不要加彩色装饰球。
- 面板和导航仍然克制，不能变成视觉主角。
- 移动端不要变成普通列表，仍然保留星路场景，只降低粒子/标签压迫感。

## 验收标准

完成后需要满足：

- 第一眼仍然像现在网站，不像换了一个项目。
- 星路更“展开”，有纵深、颗粒和水墨边缘。
- 没有建筑感、平台感、塑料感、赛博感。
- 左侧 `Robin` 文案清楚，右上漩涡没有被遮挡。
- 桌面和移动端都能拖拽/滚轮/点击节点。
- 控制台没有运行时报错。

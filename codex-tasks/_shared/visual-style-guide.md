# Robin 个人页面视觉风格指南

所有 Codex 生图任务以此共享规范为基准。

## 总体方向

克制、冷调、有呼吸感。不是"酷炫"而是"安静有力量"。

## 色板

```
背景深色  #02040b (最底层黑)
          #050a18 (深空蓝黑)
          #0d1b2a (冷灰蓝基色)
星云色    #1b2d45 (灰蓝)
          #1a1c2e (紫灰)
文字色    #f3f7ff (冷白)
强调色    #82dfff (冰蓝)
          #d8b86a (哑金)
```

## 质感原则

1. **减少细节** → 大色块、渐变优先
2. **降低饱和** → 颜色要"脏"一点、灰一点，不要纯色
3. **控制对比** → 明度差不超过 60%
4. **边缘柔和** → 不要硬边、不要锐利 mask
5. **模拟物理介质** → 像水彩晕染、像胶片颗粒、像旧照片

## 避免清单

- 高饱和（不要 #ff0000/#00ff00/#0000ff 纯色）
- 高对比 HDR 效果
- 镜头光晕 / 辉光 / 放射光
- 科幻风格元素（飞船、星环、光束）
- 密集星星 / 银河
- 清晰纹理（木纹、噪点、像素感）
- 渐变只有两个端点的线性渐变（要用多层次、多位置 stop）

## 参考风格

- James Webb 深场背景
- Edward Hopper 夜景色调
- Andrei Tarkovsky 电影中的空旷感
- 大画幅黑白胶片过曝两档的灰阶质感

## 任务模板

新建任务时复制以下结构：

```
codex-tasks/<project-name>/
├── task.json     # 任务元数据
├── 01-<scene>/
│   └── prompt.md # 画面描述
└── 02-<scene>/
    └── prompt.md
```

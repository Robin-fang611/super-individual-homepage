# 01 — Deep Space (深层背景)

用于页面最底层 (`--deep` 层，视差系数 0.1)，透明度最终在 CSS 中控制（约 30%）。

## 画面描述

极深空。几乎纯黑（#02040b→#050a18）的背景上，有极其微弱、几乎不可见的冷蓝灰渐变。不是一个"星空图"，而是一个"深渊感"的基底。

- 从画面中心到四角有极微弱 radial 渐变：中心稍微亮一点（#0a1628），四角回到纯黑
- 绝对不要星星，不要任何点状物
- 不要纹理，不要噪点
- 要像一块深色的天鹅绒，只有凑近看才能察觉色彩变化
- 视觉上应该像天文极深空摄影的"背景天光"

## 关键词

```
ultra deep space background, absolutely minimal, nearly black,
very subtle cold blue-grey radial gradient from center, velvet matte texture,
zero stars, zero noise, zero detail, zero saturation,
darkest midnight sky, astronomical background skyglow,
16:9, minimalist, cinematic color grade, restrained
```

## 调色

- 整体明度：2-8% 之间
- 色相：220°（冷蓝）
- 饱和度：趋近于 0

## 参考

可以想象 James Webb 深场照片里"没有天体的那部分背景"——纯空区域的颜色和质感。

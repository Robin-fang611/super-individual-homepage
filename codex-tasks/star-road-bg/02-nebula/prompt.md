# 02 — Nebula (中层星云)

用于页面中间层 (`--mid` 层，视差系数 0.3)，透明度最终在 CSS 中控制（约 25%）。

## 画面描述

弥散的低饱和冷色星云。不是鲜艳的发射星云，而是银河系边缘的反射星云——稀疏、暗淡、弥散。

- 大片光滑的渐变色块，边缘没有硬切
- 主色调：冷灰蓝 (#1b2d45)、带极弱的紫灰偏移 (#1a1c2e)
- 星云像一层极薄的烟雾，在深渊上轻轻飘过
- 可以有一两个非常微弱的核心区域稍微亮一点（但仍很低对比）
- 不要出现饱和的颜色（不要粉红/翠绿/亮蓝）
- 不要硬边、不要细节纹理、不要尘埃结构
- 色块边缘 feather 要非常宽，像水彩在湿纸上晕开

## 关键词

```
diffuse reflection nebula, ultra low saturation, cold grey-blue,
wispy nebula gas, thin smoke layer, watercolor bleed edges,
color field: #0d1b2a to #1b2d45 to #1a1c2e,
no bright core, no stars, no detail, no hard edges,
extremely subtle gradients, misty, atmospheric, calm,
minimalist space art, 16:9
```

## 调色

- 整体明度：8-15% 之间
- 色相：220°-240°（冷蓝到紫灰）
- 饱和度：5-10%（极低）

## 参考

像 Michal Karcz 的极简时期作品中最暗的那层背景氛围，或者像《降临》里外星飞船表面的那种大理石纹冷灰质感。

# 03 — Star Field (前景星野)

用于页面主背景层 (`--near` 层 + CSS 主背景)，直接替换 `star-road-hero-composed.png`。CSS 中还会叠加暗化渐变，所以出图可以稍亮。

## 画面描述

稀疏的冷色星野，接近真实天文摄影的深空。不是科幻密集星群，而是真实夜空的节奏感。

- 深蓝黑背景 (#050a18→#02040b 渐变)
- 星星在 40-120 颗之间，大小不一，有明确的明暗节奏
- 大部分星星是极小的点（1-3px 视尺寸），少数较亮（5-8px）
- 星星颜色：冷白 #d8e6f0 为主，极少数带极弱暖色 (#b8a88a)
- 星星分布不是均匀的，要有"聚落感"：有些区域密集，有些区域空旷
- 不要银河带（不要 Milky Way 那种密集光带）
- 不要光晕、不要炫光、不要镜头光晕
- 每颗星星的边缘要稍微模糊（模拟大气 seeing 效应），不要硬边像素点
- 右下角区域可以比左上角稍微暗一点（自然的渐进暗角）


## 调色

- 背景明度：3-8%
- 星星明度：亮点到 60%
- 色温：冷（主色相 210°-230°）
- 饱和度：趋近于 0

## 参考

深空天文摄影中"无目标天区"的星场——例如 Hubble Ultra Deep Field 中空旷区域的星星分布密度和质感，但更稀疏、更低对比。或者像 Edward Hopper 画作中夜空的平静感，而不是科幻海报。

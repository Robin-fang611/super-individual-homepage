# Codex 生图任务 — 通用规范

所有页面视觉素材在此目录结构下管理。

## 目录约定

```
codex-tasks/
├── _shared/            ← 共享风格指南、色板、字体参考
├── star-road-bg/       ← 本次：星路背景 3 张
└── (后续任务加新文件夹)
```

每个任务文件夹包含：
- `task.json` — 任务元数据（生成目标、替换目标、尺寸要求）
- `prompt.md` — 画面描述（Codex 多模态用）
- 可选：`reference.txt` / `params.json`

## 出图规范

- 格式：PNG
- 分辨率：2560×1440（背景类），其他按需
- 色彩空间：sRGB
- 文件大小：控制在 500KB 以内
- 风格：克制、冷调、低对比度、深空质感

## 替换路径

出图后放入 `assets/images/` 覆盖原文件，再在 CSS 中调整透明度/滤镜参数。
